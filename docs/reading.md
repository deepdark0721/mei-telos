# 怎么让 AI 读取你的画像

## 一、开场指令（复制即用）

新开对话时发这一句，AI 就会先加载你的画像：

```text
开始干活前，先读我的个人画像文件（profile/ 目录下的 identity、goals、
work-style、soul 四个文件），读完用一句话复述你了解到的我是谁、我在做什么，
确认无误后再进入正题。
```

画像放在哪个目录，指令里的路径就写哪个。

## 二、单一真相源

同一条信息只存一处：

- 学校、专业、年级——只写在 `identity.md`
- 目标——只写在 `goals.md`
- 偏好——只写在 `learned.md`

不要在聊天里说一遍、又在文件里写一遍两份不一致的内容。AI 以文件为准；
文件没有的，说明你还没告诉它。

## 三、验证读取是否生效

第一次用开场指令时，检查 AI 的复述是否覆盖三个关键点：

1. 你是谁（identity）
2. 你要什么（goals）
3. 它该怎么跟你配合（soul + work-style）

复述错了，当场纠正——纠正本身就是一次画像更新（见 updating.md）。
