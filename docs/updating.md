# 怎么让画像保持新鲜

画像过期比没有更糟：AI 会拿着你半年前的目标给建议。更新靠两件事——
你主动说，AI 检测到信号自动记。

## 一、更新信号表

以下话一出口，对应文件就该更新：

| 你说了什么 | 更新哪个文件 |
|-----------|-------------|
| “我大二了 / 换专业了 / 换导师了” | identity.md |
| “我改主意了 / 不想考 XX 了 / 想试试 XX” | goals.md |
| “最近在看 XX / 开始学 XX” | interests.md |
| “学会 XX 了 / 能上手 XX 了” | skills.md |
| “以后不要 XX / 这样更好” | learned.md（固定偏好） |
| “你又搞错了 / 不对，应该是 XX” | learned.md（教训） |
| “拿到了 XX / 通过了 XX” | identity.md（当前状态） |

你可以直接对 AI 说：“把这条更新进画像”，也可以只当闲聊说——养成习惯后
AI 会在对话结束前自查一遍有没有漏记。

## 二、写入三规范

1. **先读再改**：改之前先打开文件看原文，禁止整文件覆盖重写
2. **带日期**：新增条目写上当天日期，格式 `YYYY-MM-DD：内容`
3. **记变更**：文件末尾的变更记录表追加一行——出问题能回溯

## 三、敏感信息红线

以下内容**不写进画像文件**（画像往往会被同步、备份、分享给 AI 工具）：

- 手机号、身份证号、家庭住址
- 密码、密钥、银行卡号

需要 AI 知道的场景偏好（如“通知我时别打电话”），写行为偏好，不写号码本身。
